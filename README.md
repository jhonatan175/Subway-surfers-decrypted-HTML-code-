## What This Tool Does
- ✅ Decrypt Subway Surfers profile files directly in your browser
- ✅ View and edit your profile data (coins, keys, characters, etc.)
- ✅ Re-encrypt the file after editing, ready to put back into the game
- ✅ 100% HTML/JavaScript — no installation needed, no setup hassle

## 📂 Where to Find the Game File
`Android/data/com.kiloo.subwaysurf/files/profile/`

## 📖 How to Use
1. Locate and copy the content of the **encrypted** profile file
2. Open `subway-surfers-decryptor.html` in your browser
3. Paste the content into the field and click **Decrypt**
4. Edit the values however you want
5. Click **Re-encrypt**, copy the result, and replace the original file
6. ⚠️ **ALWAYS BACKUP the original file before replacing it!**
